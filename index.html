TQQQ GATE

Needs a free Alpha Vantage key — it is the only price API that sends the CORS headers Safari requires. Takes about 30 seconds at alphavantage.co. Stored only on this device.
—
Gates computed on QQQ daily closes: 20-day realised vol < 35%, 20d/250d vol ratio < 1.10, drawdown from the 250-day high better than −20% (re-entry above −10%), all three holding two consecutive sessions. The tested rule uses the Nasdaq-100 index and total returns; QQQ price tracks it closely but is not identical, so treat this as the field version of tqqq-strategy/spec.py, not a replacement for it. Reads the prior close — act at today's close. Not investment advice.
